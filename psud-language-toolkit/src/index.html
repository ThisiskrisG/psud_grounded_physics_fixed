Extensions, plugins, and imports

Extensions

Extensions expand an existing character, environment, physics rule, or storyboard beat. They should declare their primary bracket before adding behavior.

Plugins

Plugins are optional modules. A plugin can score collisions, draw replay vectors, add AI narration, or introduce a character behavior without rewriting the base prototype.

Imports

Imports are data sources such as floor-plan SVG, generated site JSON, storyboard markdown, character sheets, or environment manifests.

  • Character plugins should connect [CHARACTER] lines to [PHYSICS] actions.
  • Environment imports should connect [ENVIRONMENT] lines to [STORYBOARD] beats.
  • Physics extensions should expose hooks such as collision.recorded, body.grounded, rift.opened, and camera.shaken.
